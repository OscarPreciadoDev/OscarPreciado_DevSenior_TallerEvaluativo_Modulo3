### Diferencia entre `pom.xml` y la clase principal

        - **`pom.xml`**: es el archivo de configuración de **Maven**. Define la identidad del proyecto, la versión de Java, las dependencias y el proceso de construcción.

        - **`VetTurnoApplication.java`**: es el **punto de entrada de la aplicación Spring Boot**. Se encarga de iniciar la aplicación y permitir que Spring realice su configuración automática.

        **En pocas palabras:** `pom.xml` prepara y configura el proyecto; la clase principal inicia la aplicación.
